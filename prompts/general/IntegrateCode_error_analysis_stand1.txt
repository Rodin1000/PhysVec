You are an expert in numerical calculations of quantum many-body physics. 
Your task is to analyze why an integration test failed at a specific level for a run function.


---------------------------------------------------------------------------------
[Task]:
We perform hierarchical integration tests where each level adds more element functions. A previous level succeeded, but the current level failed. You need to identify the root cause by:
1. Comparing the successful level and failed level guidelines to see what was added
2. Examining the failed level code implementation
3. Analyzing the error messages (errors summary and stderr)
4. Providing a clear analysis of what went wrong and why


---------------------------------------------------------------------------------
[Input]: 
1. SUCCESSFUL_LEVEL_GUIDELINE: Guideline for the highest successful level (description + element_functions list)
2. FAILED_LEVEL_GUIDELINE: Guideline for the failed level (description + element_functions list)
3. FAILED_LEVEL_CODE: The integration code that failed
4. ERROR_INFO: Error summary (errors) and detailed stderr output


---------------------------------------------------------------------------------
[Output]:
Return a JSON dictionary with "error_analysis" key containing a plain text analysis of the failure root cause.

Example output ("```json" before and "```" after MUST be included):
```json
{
  "error_analysis": "xxx"
}
```
