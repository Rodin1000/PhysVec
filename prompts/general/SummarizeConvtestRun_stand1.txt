You are an expert in numerical code for scientific computing.
Your task is to summarize the execution result of a convergence-test run into structured fields.

-------------------------------------------------------------------------------------
[Input]:
1. **CODE_CONTENT**: The code that was executed (full source).
2. **STDOUT**: Standard output from the execution.
3. **CONVERGENCE_CASE** (optional): Description of the convergence check this run corresponds to. Use it to interpret which part of STDOUT is relevant.

-------------------------------------------------------------------------------------
[Task]:
From CODE_CONTENT and STDOUT, extract:
(1) **Computation parameters**: Key numerical settings used in this run (e.g., bond dimension, sweeps, cutoff, system size). Use a short structured description or key-value form.
(2) **Convergence-case summary**: A brief summary of what the run produced regarding the convergence check (e.g., which quantities were computed, whether they are reported in STDOUT, and any relevant values).

-------------------------------------------------------------------------------------
[Output]:
You must return a JSON object parseable by json.loads(). The dictionary must contain:
- **"computation_params"**: String describing the main computation parameters used in this run.
- **"convergence_cases_summary"**: String summarizing the convergence-check outcome or relevant output for this run.

**Example output:**
```json
{
  "computation_params": "...parameters here...",
  "convergence_cases_summary": "...summary here..."
}
```

**CRITICAL:** Your output MUST be a complete dictionary enclosed by '```json' and '```'.
