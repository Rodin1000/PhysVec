1. **SCIENTIFIC_RESULT_CONTENT**: Description of the scientific result test and the checkpoints that were required to be exposed. This may list multiple checkpoints (e.g., multiple quantities or conditions to verify).

You may choose relative or absolute error as appropriate; the criterion is stated in TRUTH.

-------------------------------------------------------------------------------------------------------
[Task]:
Compare the actual output from the scientific result test with the expected TRUTH for every checkpoint mentioned in SCIENTIFIC_RESULT_CONTENT, using the tolerance criterion specified in TRUTH. Determine whether the result is correct, wrong, or undetermined.

-------------------------------------------------------------------------------------------------------
[Judgment Rule - CRITICAL]:
- When ALL checkpoints satisfy the tolerance criterion stated in TRUTH, you MUST set **judge** to **"correct"**. The value of "judge" must match your conclusion in "reason".

-------------------------------------------------------------------------------------------------------
[Instructions]:
1. Read SCIENTIFIC_RESULT_CONTENT to identify every checkpoint that must be verified.
2. Parse TRUTH to extract the expected value(s) and the tolerance criterion (relative error, absolute error, or percentage as stated in TRUTH).

4. For each checkpoint, compare with the expected value from TRUTH using the criterion from TRUTH.
5. Judge the result:
   - **"correct"**: ONLY if EVERY checkpoint required in SCIENTIFIC_RESULT_CONTENT satisfies the tolerance criterion stated in TRUTH.
   - **"wrong"**: If any checkpoint fails the criterion stated in TRUTH or is clearly incorrect.
   - **"undetermined"**: If the output cannot be clearly parsed, contains errors, or the comparison cannot be reliably performed for one or more checkpoints.
6. Provide a clear reason listing which checkpoints were checked and whether each satisfied the criterion from TRUTH.

-------------------------------------------------------------------------------------------------------
[Output]:
You should return a JSON file, which can be transferred to a python dict by json.loads(). The dictionary must contain keys:
- **"judge"**: Your determination, which can ONLY be one of 'correct', 'wrong', or 'undetermined'.
