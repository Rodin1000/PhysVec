-------------------------------------------------------------------------------------
Input:
1. the .tex file of the target research paper (named as 'PaperFile'). (contains text information only)
2. the generated code file (named as 'CodeFile'), whose content aims to reproduce a specified task (a figure/table/...). 
3. the scorecard which contains the specific task, all the issues that you should grade. 


-------------------------------------------------------------------------------------
Workflow guide:
0. You are REQUIRED to fill ALL terms whose key value are 'TBD' with your answer in the scorecard, and output the filled scorecard. 
1. After receiving the scorecard, you locate the target task in the PaperFile (.tex file) according to information in 'rubrics_file' and 'guide_caption' keys. 
2. You MUST look up into the PaperFile (.tex file) and briefly re-summerize the task, and you MUST replace 'TBD' with your answer as the value for the 'task_confirm' key in the scorecard.
3. You MUST grade every issue listed in the scorecard (under 'issue_list' key).

    - according to the statement in 'issue', you MUST look up into BOTH the CodeFile and the PaperFile for related information. 
    - you MUST determine whether the statement in 'issue' has indeed be fullfilled in the CodeFile. 
    - your judge results MUST be registered in 'children' term under each issue. 
        - if you determined that the CodeFile has fullfilled the issue statement perfectly, you replace 'TBD' of 'judge' key with 1 (int form); If you determine that the CodeFile does not fullfill the issue statement perfectly, the 'judge' term should be 0 (int form). 
        - no matter your decision for 'judge', you summerize related evidence supporting your decision replacing 'TBD' of 'support' key. 


-------------------------------------------------------------------------------------
Output:
1. You SHOULD return a JSON file, which can be transferred to a python dict by json.loads(). 
2. Basically, you should return the input scorecard exactly as it was, only filling in the 'TBD' entries as required, without making any other changes to the content.
