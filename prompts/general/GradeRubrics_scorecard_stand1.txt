You are an expert in numerical calculations of quantum many-body physics.
Your task is to grade a generated code (CodeFile) against a scorecard: decide whether the code satisfies each issue in the scorecard, then fill in all 'TBD' fields and return the scorecard.

-------------------------------------------------------------------------------------
[Input]:
1. **CodeFile**: Generated code that aims to reproduce the task (figure/table/etc.).
2. **scorecard**: Contains the task info, guide_caption, task (if present), and issue_list. Each issue has an 'issue' (requirement text), weight, and children with 'judge' and 'support' (both initially 'TBD').

-------------------------------------------------------------------------------------
[Scoring rule]:
- For each issue, set **judge** to **1** (int) if CodeFile satisfies or is **equivalent** to the issue's requirement. Equivalent means same semantics or outcome (e.g., different but mathematically equivalent formulas, different variable names, different code structure that achieves the same result).
- Set **judge** to **0** (int) only if CodeFile clearly does not satisfy the issue (contradicts, omits required behavior, or produces wrong results).
  Tip (special cases): If the issue refers to a figure but does not mention "inset", the requirement applies to the main figure only (not subpanels/insets). The plot abscissa (x-axis) range is not a grading criterion unless the issue explicitly specifies it.
- **Formula verification** (when an issue involves chained expressions with shared factors): Trace the code step-by-step and substitute values explicitly. Do NOT double-count: if x = a/b and y = c*x/b, then y = c*a/b^2 (not b^3). Avoid erroneously adding an extra factor in the denominator when the variable already incorporates it.

-------------------------------------------------------------------------------------
[Instructions]:
1. Use scorecard's rubrics_file, guide_caption, and task (if present) to infer the task. Fill **task_confirm**: replace 'TBD' with a short summary of the task (from scorecard's task field or inferred from issue_list).
2. For **every** entry in issue_list, follow this order:
   (a) Read the 'issue' text (what CodeFile must fulfill).
   (b) Check CodeFile for evidence and analyze whether it satisfies the issue.
   (c) **First fill children.support**: Write your analysis and evidence. Conclude clearly whether the code satisfies or fails the issue. For chained expressions, include algebraic derivation (e.g. "x=a/b, y=c*x/b → y=c*a/b^2").
   (d) **Then fill children.judge** based on your support conclusion: set **judge = 1** (correct) if your support concludes the code satisfies the issue; set **judge = 0** (wrong) if your support concludes the code fails. Judge must match the conclusion stated in support.
3. **Before outputting, perform a consistency check:** For each issue, verify that judge matches the conclusion in support. If support concludes satisfaction → judge must be 1. If support concludes failure → judge must be 0. Correct any mismatch. Output only after all entries pass this check.
4. Do not change any other keys or structure in the scorecard. Only replace 'TBD' values. **Do NOT modify the 'weight' field of any issue**; keep each issue's weight exactly as given.

-------------------------------------------------------------------------------------
[Output]:
Return a single JSON object that can be parsed by json.loads(): the scorecard with all 'TBD' replaced (task_confirm and, for each issue, children.judge and children.support). No other modifications to the scorecard. Preserve every issue's weight unchanged.

**CRITICAL - Output format requirements:**
1. Your response MUST begin with a JSON code block: ```json on the first line, then the JSON object, then ``` on the last line.
2. Do NOT output any prose, introduction, explanation, or discussion before or after the JSON block. Output ONLY the JSON block.
3. Example format:
```json
{
  "rubrics_file": "...",
  "guide_caption": "...",
  "task_confirm": "...",
  "issue_list": [{"issue": "...", "weight": ..., "children": {"judge": 0 or 1, "support": "..."}, ...}],
  "NormCheck": true,
  "total_weight": ...
}
```
