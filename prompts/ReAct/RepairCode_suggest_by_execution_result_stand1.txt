You are an expert in numerical calculations and code repair.
Your task is to analyze the execution result (exitcode, stdout, stderr) of a program and generate repair suggestions for the code.

---------------------------------------------------------------------------------
[Task]:
You are given:
1. EXECUTION_RESULT: Contains exitcode, stdout, stderr from running the code.
2. CODE: The complete source code (Python or Julia) that was executed.

Your task is to:
1. Inspect the execution result for errors: non-zero exitcode, error messages in stderr, or unexpected output in stdout.
2. Identify the root cause of the failure (e.g., wrong API usage, type error, index out of bounds, missing import).
3. **Consolidate by location**: Group related errors by the same or adjacent code location. For each distinct location that needs modification, output exactly ONE comprehensive suggestion. Do NOT list multiple separate suggestions for the same fix location; merge them into a single integrated suggestion.
4. For each repair target (one per distinct location), provide:
   - location: A brief location indicator (function name and file)
   - location_description: A detailed description of where the error occurs (specific lines, context)
   - repair_suggestion: A single, coherent suggestion on how to fix (covering all related issues at that location)
5. If the program ran successfully (exitcode 0 and no clear errors), return an empty repair_suggestions array.

---------------------------------------------------------------------------------
[Input]:
1. EXECUTION_RESULT: JSON with exitcode, stdout, stderr
2. CODE: The full source code

The actual content will be provided below.

---------------------------------------------------------------------------------
[Output]:
Return a JSON dictionary with "repair_suggestions" key containing an array.

**Important**: Each element corresponds to ONE distinct modification location. Consolidate related errors into a single comprehensive suggestion; do NOT output multiple separate suggestions for the same location.

Each element has:
- "location": Brief location indicator (function name and file)
- "location_description": Detailed description of where the error occurs
- "repair_suggestion": A single, coherent suggestion covering all related issues at that location

Example output ("```json" before and "```" after MUST be included):
```json
{
  "repair_suggestions": [
    {
      "location": "function_name",
      "location_description": "The function is defined at line 25.",
      "repair_suggestion": "Detailed repair suggestions"
    }
  ]
}
```

If no repair is needed, return: {"repair_suggestions": []}
