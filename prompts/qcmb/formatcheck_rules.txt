**Format Rules for Generating [Qiskit] Codes for Many-Body Physics**

====================================================================================================
## **Notation**

**Function Categories:**
- **ELEMENT functions:** Functions with tags {'hamiltonian', 'circinit', 'circevol', 'effector', 'observable'}. These are fundamental building blocks that implement single steps in the calculation procedure.
    - Other functions whose names without these tags are NOT element functions, even though their functions are similar. e.g. 'correlation_matrix' is NOT an element function. 
- **Task functions:** Functions with tags {'run'}. These orchestrate ELEMENT functions to complete calculation tasks.

====================================================================================================

## **CRITICAL Format Rules**

### **Rule 1: ELEMENT Functions - No Cross-Calling**
- Functions with tags {'hamiltonian', 'circinit', 'circevol', 'effector', 'observable'}. Other functions whose names do not contain these tags are NOT element functions. 
**You are STRICTLY FORBIDDEN** to call any other ELEMENT functions within the definition of any ELEMENT function.
    - **Instead:** Define the required preceding variables as input parameters of the function.
- **Helper functions:** If an element function needs to define helper functions, **you are FORBIDDEN** to define them outside the element function. **You are REQUIRED** to define helper functions inside the corresponding element function where they are needed.

### **Rule 1b: No hardcoded lattice/system dimensions**
- **CRITICAL**: Lattice/system dimensions (e.g. L, Lx, Ly, num_sites, num_qubits) MUST be function input parameters, NOT hardcoded constants in the function body.
- Bond indices, site indices, and similar quantities MUST be computed from input parameters. You are FORBIDDEN to hardcode values like 2*4, 8, 16, or bond lists (e.g. [(4,5), (5,6)]) inside function definitions. 

### **Rule 2: Run Functions (have 'run'/'run_' in names) - Complete ELEMENT Call Chain**
**You are REQUIRED** to call ALL types of ELEMENT functions (at least one of each: 'hamiltonian', 'circinit', 'circevol', 'effector'). If 'observable' function is defined, then it MUST be called in at least one run function. 
- **You are REQUIRED** to implement a complete calculation procedure: you MUST BEGIN from constructing hamiltonian, then call other element functions ('circinit', 'circevol', 'effector', 'observable'. Sequence of these four is NOT strictly restricted)
- **You are FORBIDDEN** to call anthor 'run' function explicitly. 
- **You are FORBIDDEN** to define explicitly hamiltonian, circuits, or use quantum calculation operations (such as Statevector.from_instruction, VQE, IterativePhaseEstimation) directly in 'run' functions (must call ELEMENT functions instead). But you are ALLOWED to include some simple calculation/process if necessary. 
- **You are FORBIDDEN** to include specific numeric values in function definitions. 

### **Rule 3: Code Completeness**
- **There MUST be** at least 1 run function (have 'run'/'run_' in names). 
- **You are FORBIDDEN** to change existing run functions into other tags (such as illegal tags as 'task_'...)

### Check scope. 
- **You are FORBIDDEN** to check and modefy 'item', 'plot', 'main' and other functions. **
- **You are REQUIRED** to check ALL element functions and 'run' function definitions, not their applications in other functions.
