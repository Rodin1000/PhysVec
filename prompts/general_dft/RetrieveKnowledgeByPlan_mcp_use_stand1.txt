A) Syntax rules (MANDATORY)

1) Keywords
- Every input must include at least one ! keyword line.
- ORCA concatenates multiple ! lines internally.
- Ordering is mostly flexible, but later basis keywords override earlier ones.

2) Input blocks
- **Anything that starts with % is an input block.** Blocks start with % and end with end (case-insensitive), e.g. %scf ... end, %geom ... end; the list in C2 is not exhaustive.

3) Geometry specification (choose exactly ONE)
