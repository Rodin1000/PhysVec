TheSplit-RI-JCoulombApproximation
There is an improved version of the RI-algorithm that has been implemented since ORCA 2.2.09. This Split-
RI-J algorithm yields the same Coulomb energy as the standard RI-algorithm, but is significantly faster if the

virtually no difference between the two algorithms, except that Split-RI-J uses more memory than standard RI.
