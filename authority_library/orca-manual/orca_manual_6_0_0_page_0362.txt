Another important point to consider for hyperfine calculations concerns the choice of basis sets. You should
normally use basis sets that have more flexibility in the core region. In the present example a double-zeta basis
set was used. For accurate calculations this is not sufficient. There are several dedicated basis set for hyperfine
calculations:
• EPR-IIbasisofBaroneandco-workers: Itisonlyavailableforafewlightatoms(H,B,C,N,O,F)andis
essentiallyofdouble-zetapluspolarizationqualitywithaddedflexibilityinthecoreregion, whichshould
givereasonableresults.
• IGLO-IIandIGLO-IIIbasesofKutzelniggandco-workers: Theyarefairlyaccuratebutalsoonlyavailable
forsomefirstandsecondrowelements.
• CPbasis: Theyareaccurateforfirstrowtransitionmetalsaswell.
• uncontractedPartridgebasis:TheyaregeneralpurposeHF-limitbasissetsandwillprobablybetooexpensive
forroutineuse,butareveryusefulforcalibrationpurposes.
