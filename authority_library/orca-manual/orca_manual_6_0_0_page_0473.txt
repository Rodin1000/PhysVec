7.3.7 When should I change from the default grids?
In general, the errors from the default grids are rather small and reasonable for most applications. After bench-
marking against the GMTNK55 test set with the default !DEFGRID2, we found an error of about 0.01±0.03
kcal/mol from DFT (compared to a reference grid), and 0.05±0.10 kcal/mol for the COSX (compared to the
analyticalintegration). Wealsobenchmarkedgeometries, excitationenergiesandfrequencies, andallerrorsare
systematicallylow.
